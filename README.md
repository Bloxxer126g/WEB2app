# WEB2app
Turn any HTML file or website into an app!
(App type is based on your current OS. i.e. Windows => .exe)

How to use:
#1: Install Python! Python is required to package the app.

Head to https://python.org/ and download the latest version

#2: Download and run **main.exe**

______________________________________________________________________
## Important note:
*If you are running **MacOS or Linux**, you will need to build from source!*
*You can find instructions in **build-from-source.txt***

#### Why is this?
*PyInstaller, which is used to package this project cannot compile cross-platform. This means, as a Microsoft Windows user, I **cannot compile the app for mac or linux.***

*Another reason that applies to linux is that there are so many different formats to compile for, that it would take hours to create a virtual machine for every single one.*

*Yes, in the near future I will compile for Arch, Debian and Red Hat, though I cannot do the same for MacOS as VMs are against their ToS*
